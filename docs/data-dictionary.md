# Data Dictionary

**File:** `global-electronics-sales-data.xlsx`
**Worksheet:** `Sheet1`
**Size:** 3,000 data rows and 13 columns

| Column | Meaning |
|---|---|
| `OrderID` | Identifier recorded for an order. |
| `OrderDate` | Date recorded for the order. |
| `Region` | Sales region. |
| `Country` | Country associated with the record. |
| `Product` | Product name. |
| `Category` | Product category. |
| `CustomerSegment` | Customer segment. |
| `UnitsSold` | Number of units sold. |
| `UnitPrice` | Recorded price per unit. |
| `TotalRevenue` | Recorded revenue amount. |
| `COGS` | Cost of goods sold. |
| `Profit` | Recorded profit amount. |
| `ForecastRevenue` | Forecast revenue value in the dataset. |

## Notes

- Recorded order dates span 2018–2023.
- The workbook contains one worksheet.
- Currency units and dataset provenance have not been confirmed.
- The method used to calculate forecast revenue is not documented in the available files.
